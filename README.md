# Lampa Network Speed

Плагин для [Lampa](https://github.com/yumata/lampa), который показывает текущую скорость загрузки в шапке рядом с часами.

- Замер — скачивание тестового файла с `speed.cloudflare.com`, размер подстраивается под канал (200 КБ – 3 МБ)
- Цвет кружка под качество видео (настройка «Цвет под качество»):

  | Профиль | Зелёный | Жёлтый | Красный |
  |---|---|---|---|
  | 4K | ≥ 50 Мбит/с | ≥ 25 | < 25 |
  | Full HD (по умолчанию) | ≥ 20 | ≥ 10 | < 10 |
  | HD | ≥ 10 | ≥ 5 | < 5 |
- Режим «Только кружок»: без замера скорости, цвет по пингу (зелёный < 150 мс, жёлтый < 400, красный — выше или нет сети), трафика почти нет
- Enter с пульта / клик — внеплановый замер
- Настройки → «Скорость сети»: вкл/выкл, режим, профиль качества и интервал (15 сек – 5 мин)
- Пока открыт плеер или приложение свёрнуто, замеры не идут

## Установка

Настройки → Расширения → Добавить плагин:

```
https://cdn.jsdelivr.net/gh/VictorAdamovich/lampa-netspeed@main/netspeed.js
```

> raw.githubusercontent.com не подойдёт — он отдаёт `text/plain`, и браузер не выполнит скрипт.

## Трафик

Каждый замер качает до 3 МБ. При интервале 1 минута это до ~180 МБ в час. Если трафик лимитирован, поставь интервал 5 минут.
