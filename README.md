# Lampa Network Speed

Плагин для [Lampa](https://github.com/yumata/lampa), который показывает текущую скорость загрузки в шапке рядом с часами.

- Замер — скачивание тестового файла с `speed.cloudflare.com`, размер подстраивается под канал (200 КБ – 3 МБ)
- Цвет: красный < 5 Мбит/с, жёлтый < 25, зелёный ≥ 25
- Enter с пульта / клик — внеплановый замер
- Настройки → «Скорость сети»: вкл/выкл и интервал (15 сек – 5 мин)
- Пока вкладка/приложение скрыто, замеры не идут

## Установка

Настройки → Расширения → Добавить плагин:

```
https://cdn.jsdelivr.net/gh/<USER>/<REPO>@main/netspeed.js
```

> raw.githubusercontent.com не подойдёт — он отдаёт `text/plain`, и браузер не выполнит скрипт.

## Трафик

Каждый замер качает до 3 МБ. При интервале 1 минута это до ~180 МБ в час. Если трафик лимитирован, поставь интервал 5 минут.
