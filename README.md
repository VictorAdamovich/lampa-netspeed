# Lampa Network Speed

Плагин для [Lampa](https://github.com/yumata/lampa), который показывает текущую скорость загрузки в шапке Lampa.

- Замер — 4 параллельные загрузки с `speed.cloudflare.com` (~3 сек), первые 0.5 сек разгона TCP не учитываются; размер подстраивается под канал (250 КБ – 2.5 МБ на поток)
- Цвет кружка под качество видео (настройка «Цвет под качество»):

  | Профиль | Зелёный | Жёлтый | Красный |
  |---|---|---|---|
  | 4K | ≥ 50 Мбит/с | ≥ 25 | < 25 |
  | Full HD (по умолчанию) | ≥ 20 | ≥ 10 | < 10 |
  | HD | ≥ 10 | ≥ 5 | < 5 |
- Режим «Только кружок»: без замера скорости, цвет по пингу (зелёный < 150 мс, жёлтый < 400, красный — выше или нет сети), трафика почти нет
- Настройки → «Скорость сети»: вкл/выкл, режим, профиль качества и интервал (15 сек – 5 мин)
- Пока открыт плеер или приложение свёрнуто, замеры не идут
- После запуска Lampa первые 10 сек ничего не меряет (кружок плавно мигает серым), чтобы не мешать загрузке главной
- Во время замера скорости кружок мигает голубым

## Установка

Настройки → Расширения → Добавить плагин:

```
https://victoradamovich.github.io/lampa-netspeed/netspeed.js
```

GitHub Pages, обновляется за пару минут после пуша.

Запасная ссылка (jsDelivr, кэш до 12 часов):

```
https://cdn.jsdelivr.net/gh/VictorAdamovich/lampa-netspeed@main/netspeed.js
```

> raw.githubusercontent.com не подойдёт — он отдаёт `text/plain`, и браузер не выполнит скрипт.

## Трафик

Каждый замер качает до 10 МБ (4 потока × 2.5 МБ). При интервале 1 минута это до ~600 МБ в час. Если трафик лимитирован, поставь интервал 5 минут.
